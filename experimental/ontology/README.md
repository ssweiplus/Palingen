# Experimental Ontology Extension

This directory is reserved for optional experiments that grow out of real Palingen engagements.

It is intentionally **not** part of the required Palingen v1 workflow.

Current direction:

```text
Palingen Core Semantics
        +
Project Domain Semantic Seed
        ↓ repeated projects
Shared Domain Ontology
        ↓ only when justified
Formal OWL / SHACL / reasoning
```

## v1 rule

Do not require users to model their software in OWL before Agentification.

Semantic material should be harvested as a side effect of understanding and refactoring real systems, with provenance preserved.

See:

- `skills/palingen/references/domain-semantic-seeding.md`

## Possible future artifacts

Examples only:

```text
palingen-core.ttl
project-domain-seed.ttl
shared-domain.ttl
```

These names do not define a required storage model.

## Non-authoritative

Ontology experiments are semantic projections. They must not become the authoritative source for execution state, operational artifacts, permissions, or side effects.
